## [0.1.0] - 2026-07-19

### Added
- Verse library with add, edit, and archive capabilities
- Practice sessions for memorization drills
- Testing with recorded results and score tracking
- Progress and comfort-level tracking with statistics
- JSON data export and import functionality
- Offline-first cross-device sync to Supabase backend with email and password authentication
- Verse grouping via named shelves with active-set picker for Practice and Test modes

### Changed
- Upgraded to Expo SDK 56, React Native 0.85, and React 19

### Fixed
- Cross-account data leak on shared-device account switch
- Usability issues identified during daily use
